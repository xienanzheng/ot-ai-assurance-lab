# Changelog

## Hosted preview — 18 September 2026

- Deployed isolated water, nuclear and grid sessions to the public domain with real Workers AI inference.
- Forward proposal schemas as structured-output constraints; the initial production test exposed an overlong model explanation that validation correctly rejected.
- Verified public session isolation, gate decisions, live browser telemetry and evidence downloads. See [production verification](docs/VERIFICATION_2026_09_18.md).

## 0.1.0 — Research preview

- Water, conceptual nuclear and five-bus grid simulation with deterministic controls and bounded AI supervision.
- Local Ollama decisions, evidence inspection, controlled research scripts and recorded activation-probe artifacts.
- Durable critical-event evidence and versioned lessons requiring operator review before retrieval.
- Public recorded dashboard and a separate hosted-session package using Cloudflare Containers and a model API.
- MIT license, contributor guidance and automated checks.

This release does not establish production readiness, verified air-gapping, faithful reasoning extraction, or improved process recovery. The recorded water trial did not improve recovery. At the time of 0.1.0, the full hosted simulator still required Workers Paid and production acceptance testing; see the subsequent hosted-preview verification above.
