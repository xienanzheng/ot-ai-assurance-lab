# Changelog

## 0.1.0 — Research preview

- Water, conceptual nuclear and five-bus grid simulation with deterministic controls and bounded AI supervision.
- Local Ollama decisions, evidence inspection, controlled research scripts and recorded activation-probe artifacts.
- Durable critical-event evidence and versioned lessons requiring operator review before retrieval.
- Public recorded dashboard and a separate hosted-session package using Cloudflare Containers and a model API.
- MIT license, contributor guidance and automated checks.

This release does not establish production readiness, verified air-gapping, faithful reasoning extraction, or improved process recovery. The recorded water trial did not improve recovery. The full hosted simulator needs Workers Paid and a production acceptance test before public use.
